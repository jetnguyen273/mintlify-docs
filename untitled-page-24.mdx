title: "Tham khảo: Mã trạng thái lệnh"

Đây là các giá trị được trả về trong các response liên quan đến lệnh (Section C, D, E, F), giúp bạn ánh xạ mã trạng thái sang trạng thái dễ đọc cho người dùng trong UI.

## 10.1 Trạng thái lệnh phái sinh

| **Mã** | **Ý nghĩa** |
| :-- | :-- |
| BB | Đang gửi lệnh |
| DD | Đã hủy |
| DE | Yêu cầu hủy gửi thành công |
| DN | Yêu cầu hủy thất bại |
| DR | Yêu cầu hủy bị sàn từ chối |
| DS | Hủy thành công |
| EE | Yêu cầu sửa gửi thành công |
| EN | Yêu cầu sửa thất bại |
| ES | Sửa thành công |
| FF | Lệnh được giải phóng |
| GG | Giải phóng lệnh thành công |
| MM | Không đủ số dư tại Core Banking |
| NN | Chờ gửi |
| PP | Lệnh hết hạn |
| RR | Bị người mua từ chối |
| SD | Đang hủy |
| SE | Chờ sửa lệnh |
| SR | Bị sàn từ chối |
| SS | Đã gửi |
| TP | Khớp một phần |
| TS | Khớp toàn bộ |
| U1 | Lệnh gốc chờ hủy |
| U5 | Chờ kết quả hủy/sửa |
