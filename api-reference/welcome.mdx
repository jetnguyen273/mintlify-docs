Welcome to **PHS OpenAPI (Flash API)** — the official API platform of Phu Hung Securities (PHS).

Flash API helps developers, partners, and institutions connect to PHS trading systems and build modern trading applications for the Vietnam stock market.

<Card title="Register for PHS OpenAPI" icon="file-signature" href="https://flashapi.phs.vn/docs/registration-form">
  To start integrating with the PHS Flash API, follow the step-by-step registration instructions.
</Card>

## What you can do

With Flash API, you can:

- **Build trading applications** for equities and derivatives
- **Develop algorithmic trading strategies** with real-time data
- **Integrate brokerage services** into your platform
- **Access real-time market data** and account information
- **Manage trading operations securely** with modern authentication
