This appendix defines the **service scope**, **operational principles**, and **technical framework** governing the use of **PHS OpenAPI**.

Detailed API specifications—including available endpoints, request and response schemas, authentication methods, rate limits, error codes, versioning, SDKs, and sample code—are maintained separately in the **PHS API Documentation** and may be updated by PHS from time to time.

Developers are responsible for ensuring their applications remain compatible with the latest published API specifications.

<Note>
  In the event of any inconsistency between this appendix and the latest API Documentation, the API Documentation published by PHS shall prevail for all technical implementation details.
</Note>
